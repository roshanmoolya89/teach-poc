loops/ForEach.java

Every item, once, in order

No counter, no condition, no update. Java hands you the items one at a time, first to last, and stops when there are none left.

The syntax

for (type item : collection) {
    // body: runs once for every item
}
type
The type of one element. For an int[] it is int.
item
A variable that holds a copy of the current element on each lap: s
:
Read it as “in”: for each int s in scores.
collection
The array or collection to walk through: scores

The shape of it

s is now — visited 0 left 3

Change the input

The code

int[] scores = {80, 65, 92}; for (int s : scores) {    System.out.println(s);}

What to point out

  • There is no index anywhere. You cannot get it wrong, which is why off-by-one errors disappear.
  • s is a copy of the element. Assigning to s inside the body does not change the array.
  • It always goes first to last, one at a time. No skipping every second item, no going backwards.
  • Need the position, or need to change the array? Use the regular for with scores[i].
