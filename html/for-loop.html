Output

What to point out

  • Three parts, three different schedules. int i = 1 runs once. i <= 5 runs before every lap. i++ runs after every lap.
  • The check always runs one more time than the body — the last check is the one that fails and ends the loop.
  • i is declared inside the for, so it does not exist after the loop finishes.
  • If the condition is false the very first time, the body never runs at all. That is not an error.

Try this with the class

  • Step through once and count aloud: check, body, update, check, body…
  • Ask how many times the check runs for five laps, then confirm with the counter.
  • Set start to 6 and end to 5. Ask what prints before you run it.
  • Set the update to 2. Which numbers print now, and how many laps?
