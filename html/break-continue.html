Skip one, stop at another

Two ways to cut a lap short. continue abandons this lap and moves on to the next. break abandons the whole loop.

The syntax

for (…) {
    if (condition) continue;   // skip the rest of this lap
    if (condition) break;      // leave the loop
    // rest of the body
}
continue
Skips whatever is left of the body for this lap. In a for loop the update still runs, then the condition is checked as usual.
break
Ends the loop on the spot. No update, no further checks. Execution carries on after the closing brace.
condition
Both are almost always inside an if. On their own they would fire on the very first lap.

The code

for (int i = 1; i <= 10; i++) {    if (i == 3) continue;   // skip this iteration    if (i == 6) break;      // exit the loop entirely    System.out.println(i);}

What to point out

  • continue does not end the loop. The lap is cut short, i++ still runs, and the next lap starts.
  • break skips everything: the rest of the body, the update, and every lap that was still to come.
  • The loop said ten laps, but the header no longer tells the whole story. You have to read the body to know.
  • Order matters. The continue line is read first, so if both match the same i, break is never reached.
