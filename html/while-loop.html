loops/While.java

Chop until nothing is left

No counter and no fixed number of laps. The loop keeps going for as long as the condition holds, so something inside the body has to change it.

The syntax

while (condition) {
    // body: the statements to repeat
}
condition
A boolean checked before every lap. True runs the body, false ends the loop: number > 0
body
Runs once per lap. It must change something the condition reads, or the loop never ends: number = number / 10
zero laps
If the condition is false the first time, the body does not run at all.

The shape of it

number is now — body ran 0× check ran 0×

Change the input

The code

int number = 1234;int digits = 0; while (number > 0) {    number = number / 10;    digits++;}System.out.println("Digits: " + digits);

Output

What to point out

  • There is no counter in the header. You cannot tell how many laps there will be without knowing the number.
  • number / 10 is integer division, so the last digit is simply dropped: 1234 / 10 is 123.
  • The check comes first. Like for, it runs one more time than the body.
  • The body changes number, and the condition reads number. Take that line away and the loop never ends.

Try this with the class

  • Ask how many laps 1234 will take before you press Run, then try 99999.
  • Set the number to 0. Ask what prints, then ask whether 0 really has zero digits.
  • Ask what would happen if number = number / 10 were deleted.
