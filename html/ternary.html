Ternary.java

One line, one decision

The whole if / else squeezed into a single expression. Drag the marks and watch which side of the colon wins.

The syntax

type variable = condition ? valueIfTrue : valueIfFalse;
condition
A boolean expression, checked first: marks >= 40
valueIfTrue
The value the whole expression takes when the condition is true. It sits between ? and :
valueIfFalse
The value it takes otherwise. It sits after the :
type variable
Where the chosen value is stored. Both values must fit this type.

The shape of it

condition is true result is "Pass"

Change the input

The code

int marks = 45;String result = (marks >= 40) ? "Pass" : "Fail";System.out.println("The student has: " + result);

Output

What to point out

  • Read it aloud: is marks at least 40? if yes “Pass”, otherwise “Fail”.
  • Only one side ever runs. The other is never evaluated.
  • Both sides must hand back the same type — here, two Strings.
  • A ternary is an expression: it produces a value, so it can sit on the right of an =. A plain if cannot.

Try this with the class

  • Set marks to exactly 40. Does it pass? Why does >= matter?
  • Drag marks to 39, then 41. Watch the highlight jump sides.
  • Raise the pass mark above the marks without touching marks.
  • Ask: could you write this as an if / else? How many lines would it take?
