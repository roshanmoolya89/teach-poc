IsRaining.java

Two doors, one opens

A boolean picks the room, and Java runs exactly one block. Flip the switch and watch the light move.

The shape of it

blocks that run: 1 branch taken: if

Change the input

boolean isRaining

A condition in Java must be a boolean. isRaining already is one, so it needs no comparison.

The code

boolean isRaining = true;if (isRaining) {    System.out.println("It's raining. Don't forget your umbrella!");} else {    System.out.println("It's not raining. Enjoy your day!");}

Output

What to point out

  • The condition inside if ( ) must be true or false — nothing else. Java will not accept a number here the way C does.
  • Exactly one block runs. Never both, never neither.
  • The else block is the catch-all for every other case.
  • if (isRaining == true) works but is noise. Compare booleans to nothing.

Try this with the class

  • Before flipping the switch, ask which line will print. Then flip it.
  • Ask what happens if you delete the else block entirely.
  • Ask: how would you add a third case, like “it is snowing”? That is the next topic.
