Switch.java

A dial with seven stops

One value, compared against labelled cases until it matches. Then take the brakes off and watch it fall through.

The syntax

switch (expression) {
    case value1:
        // runs when expression equals value1
        break;
    case value2:
        // runs when expression equals value2
        break;
    default:
        // runs when no case matches
}
expression
Evaluated once. Its value is compared against each case: day
value1
A constant to match, such as 1 or "MON". It cannot be a variable or a range.
break
Leaves the switch. Without it, execution falls through into the next case.
default
Optional. Runs when none of the cases match, like a final else.

The shape of it

Push it past 7 or down to 0 to reach default.

What to point out

  • Reach for switch when one variable is tested against many fixed values. It says pick one of these more clearly than a long else-if chain.
  • Case labels must be constants. You cannot write case day > 5: — that is else-if territory.
  • break leaves the switch. Without it, execution keeps running straight down through the cases below.
  • default catches everything unmatched. It is not required, but leaving it out means dayName may never be assigned.

Try this with the class

  • Set day to 3, then switch the breaks off. Ask why Wednesday became “Invalid day”.
  • With breaks off, try day 7. Only one case below it, and it is default.
  • Set day to 9 and ask which line saves the program.
  • Ask: when would falling through on purpose be useful? (Grouping cases 6 and 7 as “weekend”.)
