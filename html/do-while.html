loops/DoWhile.java

Act first, ask after

The body sits above the condition, and that is the order it runs in. The menu is always shown once before anyone asks whether to show it again.

The syntax

do {
    // body: the statements to repeat
} while (condition);
body
Runs first, before any check. So it always runs at least once.
condition
A boolean checked after every lap. True goes round again, false ends the loop: choice != 2
;
The closing semicolon is required here. It is the one loop that ends with one.

The shape of it

choice is now — body ran 0× check ran 0×

Change the input

The code

int choice;do {    System.out.println("Menu: 1. Play  2. Quit");    choice = 2; // typed by the user} while (choice != 2);

What to point out

  • Read the code top to bottom: body, then condition. That is exactly the order Java runs it in.
  • The body and the check run the same number of times. In for and while the check runs once more.
  • choice has no value when the loop starts. That is fine, because the body gives it one before the condition reads it.
  • It suits anything that must happen before you can decide: showing a menu, asking for a password, reading input to validate.

Try this with the class

  • Leave the slider on 1. The user quits straight away, yet the menu still prints. Ask why.
  • Move it to 4 and ask how many times the menu prints before you run it.
  • Ask what a plain while (choice != 2) would do with choice not yet set.
  • Delete the final semicolon in your editor and read the compiler error together.
